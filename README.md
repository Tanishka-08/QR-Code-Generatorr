# QRgeneraterrrrrr

A Spring Boot–based QR Code Generator that supports:

- Text QR generation
- URL QR generation
- Image upload → QR
- PDF upload → QR

## Features
- ZXing QR generation
- Public file access via HTTP
- Scannable using camera / Google Lens
- REST API–based backend

## Tech Stack
- Java
- Spring Boot
- ZXing
- Maven

## How It Works
1. User provides text, link, image, or PDF
2. Backend processes input
3. QR code generated and saved
4. QR opens content when scanned

## Future Enhancements
- Cloud storage integration
- QR expiry
- Authentication
